# Watch

Красивые цифровые часы на Java Swing с аккуратным тёмным оформлением.

## Возможности
- Крупное отображение времени в формате `HH:mm:ss`
- Дата на русском языке (`день недели, число месяц год`)
- Обновление времени и даты каждую секунду
- Более приятный интерфейс: «карточка» часов, мягкие цвета и центровка окна

## Запуск
```bash
javac Digital_clock.java
java Digital_clock
```
